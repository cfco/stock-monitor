# Stock Monitor 桌面悬浮窗 v5.1

Windows 11 桌面股票监控悬浮窗，无边框、置顶、半透明、可拖拽。支持 A股、港股、美股、韩股实时行情，目标价 + 单日涨跌幅双预警，鼠标悬停显示 1 分钟 K 线图。

## 功能特性

- **悬浮窗模式**：无边框置顶显示，半透明背景，鼠标拖拽移动，双击任意位置关闭程序
- **多市场支持**：A股（腾讯/新浪/东方财富三接口轮询）、美股/韩股（Yahoo Finance，含盘前盘后）
- **美股盘前盘后**：自动检测交易时段，显示盘前/盘后价格
- **双预警系统**：
  - 目标价预警（跌破/涨破/双向）
  - 单日涨跌幅预警（绝对值模式：设 3% 则涨3%或跌3%都触发）
- **预警变色**：触发条件时卡片变绿色，未触发为默认黑色，不闪烁
- **1 分钟 K 线悬浮图**：
  - 鼠标悬停任意股票 0.3 秒后弹出 K 线图，显示完整股票名称和最新价
  - 蜡烛图渲染，红涨绿跌，标注最高/最低价和时间
  - 三档尺寸可选：小（320×180，默认）/ 中（640×360）/ 大（960×540）
  - 智能定位：自动避开屏幕边缘
  - 零延迟显示：K 线随实时行情预加载并缓存，悬停时直接读取
  - 美股：Yahoo chart API 一次请求同时返回行情 + K 线
  - A股：后台线程每 30 秒异步预加载
- **三接口轮询**：A股数据通过腾讯、新浪、东方财富三个免费接口轮流请求，避免单一接口限流
- **批量请求**：每个接口一次请求多只股票，减少网络开销
- **紧凑布局**：窗口宽度 200-320px，单行卡片显示完整行情
- **滚动支持**：最多显示 10 条，超出可通过垂直滚动条查看
- **可视化设置**：内置设置对话框，增删改监控股票、调整刷新间隔和数据源，保存即生效

## 快速开始

### 环境要求

- Windows 10/11
- Python >= 3.10
- [uv](https://docs.astral.sh/uv/) 包管理器

### 安装

```bash
uv sync
```

### 运行

```bash
# 方式1：无窗口启动（推荐，无 cmd 黑框）
双击 run.vbs

# 方式2：命令行启动
uv run floating_window.py

# 方式3：bat 启动
双击 run.bat
```

## 使用说明

### 界面操作

| 操作 | 效果 |
|------|------|
| 单击拖拽空白区域 | 移动悬浮窗位置 |
| 双击窗口任意位置 | 关闭程序 |
| 鼠标悬停股票卡片 | 显示 1 分钟 K 线悬浮图（含完整股票名称和最新价，0.3 秒防抖） |
| 鼠标离开股票卡片 | K 线悬浮图自动隐藏 |
| 点击底部 ⚙ | 打开设置对话框（保存后自动刷新） |

### 设置对话框

点击底部栏 ⚙ 按钮打开设置：

- **刷新间隔**：数据刷新周期（1-120 秒）
- **K线图大小**：small（320×180，默认）/ medium（640×360）/ large（960×540）
- **数据源**：auto（自动路由）/ tencent / yahoo / tdx
- **监控列表**：支持新增/删除/编辑股票
- **预警条件**：
  - 目标价 + 方向（跌破/涨破/双向）
  - 目标涨跌幅 + 方向（跌/涨/双向）

保存设置后程序会自动停止旧监控、应用新配置、立即重启监控，无需手动刷新。

### 配置文件

配置保存在 `scripts/watchlist_config.json`：

```json
{
  "interval": 5,
  "kline_size": "small",
  "source": "auto",
  "alerts": [
    {
      "code": "sh601398",
      "name": "工商银行",
      "target": 7.50,
      "dir": "below",
      "target_pct": 3.0,
      "pct_dir": "both",
      "position": "",
      "note": ""
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `interval` | 刷新间隔（秒） |
| `kline_size` | K线图大小：small/medium/large |
| `source` | 数据源：auto/tencent/yahoo/tdx |
| `code` | 股票代码 |
| `name` | 股票名称 |
| `target` | 目标价格（null 表示不监控） |
| `dir` | 价格方向：below/above/both |
| `target_pct` | 涨跌幅阈值（null 表示不监控） |
| `pct_dir` | 涨跌幅方向：below/above/both |
| `position` | 持仓信息（可选） |
| `note` | 备注（可选） |

## 支持的股票代码格式

| 市场 | 代码格式 | 示例 |
|------|----------|------|
| A股 | sh/sz + 6位数字 | sh601398、sz000001 |
| 美股 | 字母代码 | AAPL、QQQ、SPY |
| 港股 | hk + 数字 | hk00700 |
| 韩股 | kr + 数字 | kr005930 |

## 数据源说明

### A股（三接口轮询）

| 数据源 | 接口 | 特点 |
|--------|------|------|
| 腾讯 | `qt.gtimg.cn` | 批量请求，稳定 |
| 新浪 | `hq.sinajs.cn` | 需要 Referer 头 |
| 东方财富 | `push2.eastmoney.com` | HTTP 接口，响应快 |

三个接口轮流使用（腾讯 → 新浪 → 东方财富 → 腾讯...），每个接口只承受 1/3 的请求频率，有效避免限流。

### 美股/韩股

| 数据源 | 接口 | 特点 |
|--------|------|------|
| Yahoo Finance | `query1.finance.yahoo.com` | 支持盘前盘后，一次请求同时返回行情和 K 线 |

### A股 K 线

| 数据源 | 接口 | 特点 |
|--------|------|------|
| 东方财富 | `push2his.eastmoney.com` | 1 分钟 K 线，`klt=1` 参数 |

## 项目结构

## 技术栈

- **GUI 框架**：PySide6（Qt for Python）
- **行情数据**：腾讯/新浪/东方财富接口（A股）、Yahoo Finance API（美股/韩股）、通达信协议（eltdx，可选）
- **K 线数据**：东方财富 K 线接口（A股）、Yahoo chart API（美股/韩股）
- **Python**：>= 3.10
- **包管理**：uv

## 依赖

- `PySide6 >= 6.5.0` — GUI 框架
- `eltdx >= 0.1.0` — 通达信行情协议（可选，A股备用源）
